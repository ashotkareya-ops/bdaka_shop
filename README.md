# BDAKA SHOP

Первая рабочая основа Telegram-магазина на Python, aiogram 3 и PostgreSQL.

## Возможности
- Регистрация пользователей и реферальный параметр `/start ref_telegram_id`
- Каталог категорий и товаров
- Профиль и внутренний баланс
- Создание заказов
- Выдача CDK из собственного склада
- История заказов и транзакций
- Административные команды для управления каталогом, балансом и складом

## Запуск локально

1. Установить Python 3.12+ и PostgreSQL.
2. Создать БД и пользователя либо запустить `docker compose up -d db`.
3. Скопировать `.env.example` в `.env` и указать токен бота и свой Telegram ID в `ADMIN_IDS`.
4. Установить зависимости: `pip install -r requirements.txt`.
5. Запустить: `python main.py`.

При первом запуске таблицы создаются автоматически.

## Админ-команды
- `/admin` — справка
- `/addcategory Название` — создать категорию
- `/addproduct CATEGORY_ID | Название | Цена_руб | Описание` — создать товар
- `/addkey PRODUCT_ID | CDK` — добавить код на склад
- `/credit USER_ID СУММА` — начислить баланс (только после фактического получения оплаты!)
- `/orders` — последние заказы

Пример:
`/addproduct 1 | ChatGPT Go 1 месяц | 377 | CDK на 1 месяц`

## Важно
Платёжный провайдер не подключён: нельзя считать заказ оплаченным только по сообщению пользователя. Для запуска продаж подключите легальный платёжный способ и проверяйте подтверждение на стороне провайдера. Если продаёте цифровые товары внутри Telegram, изучите действующие требования Telegram Stars.

Интеграция Sandromania пока является интерфейсом-заготовкой. Не храните пароли, сессионные файлы или токены поставщика в коде и не автоматизируйте доступ вопреки правилам поставщика. Подключайте только документированный или явно разрешённый способ.


## Sandromania Partner API

В `.env` добавьте `SANDROMANIA_API_KEY` и `SANDROMANIA_API_SECRET`.
Не публикуйте эти значения и не отправляйте их в чаты.

После создания локального товара свяжите его с ID товара поставщика:
`/linksupplier LOCAL_PRODUCT_ID SUPPLIER_PRODUCT_ID`

Администраторские команды:
- `/supplierproducts` — получить каталог поставщика
- `/supplierbalance` — получить баланс поставщика

При покупке бот сначала выдаёт локальный CDK, если он есть. Если локального кода нет,
но товар связан с Sandromania, бот создаёт заказ через подписанный HMAC-запрос.
Поставщик может вернуть код сразу либо статус обработки. Для асинхронного статуса
нужно проверить фактическую схему ответа API и при необходимости настроить polling.

В текущем адаптере распознаются распространённые поля `order_id`, `id`, `status`,
`cdk`, `code`, `key`, `activation_code`, включая вложенные JSON-объекты.
Перед реальными продажами протестируйте API на тестовом товаре и уточните у поддержки
точную схему успешного/ошибочного ответа и поведение отложенных заказов.

## Важно о миграции БД

Если вы уже запускали старую версию проекта и таблицы созданы, `create_all()` не добавит
новые колонки в существующие таблицы. Для тестового проекта проще пересоздать пустую БД
до добавления реальных пользователей/заказов либо создать миграцию Alembic.
Не удаляйте рабочую базу с реальными заказами. SQL-миграции из `migrations/` нужно
применять к существующей PostgreSQL базе вручную в порядке номеров. Для поддержки
заказов с количеством примените `migrations/006_order_quantity.sql` к той же базе
(например, через `psql "$DATABASE_URL" -f migrations/006_order_quantity.sql`):
она добавляет `orders.quantity` и снимает ограничение «один ключ на один заказ».
Сделайте резервную копию базы перед применением миграции.

## Публичный адрес BDAKA STORE API для партнёров

Чтобы покупатели могли подключать свои сайты и Telegram-боты из интернета, API должен быть развёрнут отдельно на публичном сервере с HTTPS-доменом. В `.env` основного бота задайте `API_PUBLIC_URL=https://ваш-домен-api`, затем перезапустите бота. Этот адрес отображается в меню «Партнёрам / API». Локальный `127.0.0.1:8000` не является публичным адресом и не подходит внешним партнёрам.

Партнёры используют свой обычный баланс BDAKA SHOP: отдельный баланс для API не создаётся.
