# Оплата через Crypto Bot (Crypto Pay)

## Как это работает
1. Покупатель жмёт «Купить» → «🪙 Оплатить криптой (Crypto Bot)».
2. Бот создаёт заказ (PENDING) и счёт в Crypto Pay на сумму в ₽ (цена с вашей наценкой). Покупатель платит в USDT/TON и т.д. по курсу Crypto Bot.
3. Фоновая проверка каждые 15 сек (или webhook) видит оплату → заказ PAID → бот покупает товар у Sandromania через API → выдаёт код покупателю.
4. Ваша маржа = розничная цена − supplier_cost (наценка задаётся в боте, по умолчанию 30%).

Повторная выдача и двойная закупка исключены: заказ блокируется в БД и «захватывается» один раз.

## Настройка
1. В @CryptoBot: Crypto Pay → Create App → скопируйте API Token. (Для теста есть @CryptoTestnetBot и `CRYPTO_PAY_TESTNET=true`.)
2. В `.env`:
```
CRYPTO_PAY_TOKEN=...
CRYPTO_PAY_ACCEPTED_ASSETS=USDT,TON
```
3. Перезапустите бота. Миграции БД не нужны (используются существующие таблицы orders/payments).
4. Webhook необязателен. Если нужен: `WEBHOOK_SERVER_ENABLED=true`, HTTPS-прокси на `127.0.0.1:8080` и URL `https://ВАШ-ДОМЕН/api/payments/cryptobot/webhook` в Crypto Pay → My Apps → Webhooks.

## Перед запуском продаж
- Проверьте на тестнете: оплата, истёкший счёт, кнопка «Проверить оплату».
- Купите один реальный дешёвый товар и убедитесь, что Sandromania возвращает код в ожидаемом поле.
- Держите на балансе у Sandromania запас: если баланса не хватит, клиент уже заплатил, а закупка упадёт. Бот пришлёт админам предупреждение — тогда выдайте товар вручную или сделайте возврат.
- Возвраты автоматически не делаются.
