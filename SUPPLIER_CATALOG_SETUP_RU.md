# Этап 1 — автоматический каталог Sandromania

## Что добавлено
- Команда `/syncsupplier` загружает каталог Sandromania и импортирует/обновляет товары в PostgreSQL.
- Товары связываются по паре `supplier_name + supplier_product_id`.
- Закупочная цена и наличие хранятся отдельно от розничной цены.
- Существующие розничные цены и флаги активности сохраняются при повторной синхронизации.
- Новые товары импортируются выключенными и с ценой `0`, чтобы случайно не продавать по закупочной цене.
- `/setprice PRODUCT_ID ЦЕНА` задаёт розничную цену и активирует товар.
- В клиентском каталоге скрываются товары с нулевой розничной ценой, выключенные товары и товары, отмеченные поставщиком как недоступные.

## Важно перед запуском
1. Сделай резервную копию базы PostgreSQL.
2. Примени миграцию `migrations/003_supplier_catalog.sql` к базе `bdaka_shop`.
3. Проверь `.env` локально: должны быть действующие `SANDROMANIA_API_KEY` и `SANDROMANIA_API_SECRET`. Не отправляй их в чаты и не включай `.env` в архив.
4. Запусти бота и выполни `/syncsupplier` от имени администратора.
5. Посмотри `/products`, затем для нужных товаров установи розничную цену через `/setprice`.

## Ограничения текущего этапа
Формат ответа Sandromania может отличаться от распространённых полей, которые понимает нормализатор. Если API использует иные имена полей, синхронизация безопасно остановится или пропустит неподходящие записи; потребуется адаптировать `services/supplier_sync.py` по фактическому примеру ответа API без секретов.
Автоматический запуск синхронизации по расписанию и покупка нескольких единиц у поставщика пока не включены.
Оплата не подключена на этом этапе.
